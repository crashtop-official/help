The help center has a new home. Three things changed.

## Guides follow a round

The home page shows one round as a curve with five stages. Each stage links to the guide for that moment, so you can start from where you are stuck.

## Search filters as you type

Type a word in the search box and the guide list narrows straight away. The topic tabs do the same by subject.

## One place to ask

If a guide does not answer your question, write to [{{ site.support_email }}](mailto:{{ site.support_email }}) and include the round ID.
